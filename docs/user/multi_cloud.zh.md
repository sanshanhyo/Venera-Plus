# 多网盘存储

VeneraPlus 可通过内置 OpenList 内核连接百度网盘、夸克网盘、115 网盘、123 云盘、OneDrive 和 Google Drive；WebDAV 仍可作为一个独立账号使用。

内置内核由 Venera-OpenList-Core 独立构建并随应用打包；应用只使用已发布的固定内核版本，不会在设备上下载或运行 OpenList 服务。

在“存储与同步”的网盘账号管理页点击“添加”，先进入网盘来源列表，再点击来源打开对应账号配置页，填写信息或登录授权后，点击页面底部固定的“保存并测试连接”按钮。编辑已有账号时直接进入对应配置页；从配置页返回可重新选择来源，从来源列表返回则取消添加。百度网盘、115 网盘、123 云盘和 OneDrive 可点击“登录并授权”，在应用的 WebView 中完成官方授权并自动填入令牌。授权及在线令牌刷新继续使用 OpenList 官方 API；应用不会把 OpenList HTTP 服务暴露到网络。

令牌自动授权统一使用“OpenList 提供的参数”，分别对应 115 验证登录（OAuth App）、123 验证登录（OAuth官方）、百度验证登录（OAuth App）和 OneDrive 个人版本（OAuth App）。无需填写客户端 ID 或应用密钥。

夸克改用 `Quark` Cookie 驱动。点击“登录并授权”后在应用 WebView 中登录夸克官网，应用确认能读取网盘目录后，通过原生 Cookie 存储提取包括 HttpOnly 在内的完整 Cookie 并回填；也可手动填写 Cookie。保存后测试连接。已有 `QuarkOpen` 账号需重新登录，保存时保留账号标识及已配置的目录，不再使用旧令牌、AppID 或 SignKey。

Google Drive 仍使用 [OpenList Token 页面](https://api.oplist.org/) 手动获取授权。使用令牌的网盘也可直接填写令牌。百度、123、OneDrive 和 Google Drive 需要刷新令牌，115 需要访问令牌与刷新令牌。

“设置 → 存储与同步”按用途集中展示网盘账号、在线漫画库、应用数据同步和漫画归档备份，并显示当前账号、目录及同步状态。账号只需添加一次，各用途共用授权；选择账号时可直接添加新账号，完成后继续当前配置。首次成功连接账号后，也可直接选择用途。

“设置 → 来源与服务 → 内容来源”统一管理网站源和远程漫画库，并按类型分组。点击“添加”后选择来源类型：网站源可从仓库安装或通过链接、文件导入；远程漫画库直接选择网盘账号和漫画目录，也可在配置途中新增账号。“存储与同步”中的“在线漫画库”以及发现、搜索中的来源管理入口均打开同一页面。

“在线漫画库”可为每个漫画库选择一个账号和一个或多个识别目录。目录会合并展示；相同完整远端路径的漫画只显示一次，不同目录下的同名漫画会分别显示。应用数据同步和漫画归档备份各自选择一个账号和一个目录：前者同步设置、收藏、阅读记录等应用数据，后者备份和恢复 CBZ 漫画文件。

选择目录时，点击文件夹名称进入，点击行尾选框勾选；“当前文件夹”一行可选择当前目录，包括根目录和空文件夹。跨目录浏览会保留勾选，底部显示已选数量，点击右下角“完成”返回配置页；返回键取消本次选择。漫画库可多选，同步和备份只允许选一个目录。

主页可在“收藏”和“云端”之间切换，并记住上次选择。在云端视图点击“选择云端目录”，或进入“设置 → 存储与同步 → 主页云端目录”，选择一个已有账号和一个目录；更换账号后需重新选择目录。绑定后打开云端视图，每次只展示当前目录的直接子项，点击文件夹逐级进入，返回父目录时恢复原来的页码。绑定的根目录始终作为浏览入口，主页目录无需先建立在线漫画库或等待递归扫描。

云端主页会识别图片漫画、单文件漫画及 PDF 集合。一个子目录至少包含一个 PDF、所有有效直接子文件均为 PDF，且没有有效子目录时，默认作为 PDF 漫画集合；系统杂项、明确的封面和元数据辅助文件不参与判断。进入集合后仍按原文件名逐个打开 PDF，不根据文件名新增卷／话标记，也不合并各文件的阅读进度。格式混合的目录继续作为普通文件夹；长按目录或点击行尾的“识别方式”，可选择“自动识别”“作为普通文件夹”或“作为一部漫画”进行修正。

云端主页采用固定一屏一页，底部按钮切换页面；Android 默认使用音量上键切到上一页、音量下键切到下一页，在“云端主页设置”中可关闭或反转方向。首尾不循环，也不跨目录翻页。切入阅读器后由阅读器接管音量键。当前屏和下一屏的目录识别及必要封面会后台预加载，已有缓存可先显示；慢速预加载不会阻塞目录翻页或进入文件夹。

在线漫画库支持图片目录和远端 ZIP/CBZ、图片型 EPUB、PDF；每个文件作为一本漫画。ZIP/CBZ 可包含单个顶层目录、章节目录及可选的 `metadata.json`。应用按需读取归档尾部、中央目录和所需图片；PDF 按需读取文档结构并逐页渲染。封面在显示时加载并缓存，阅读页复用图片缓存。布局示例和元数据规则见[漫画导入与在线阅读](import_comic.zh.md#zipcbz图片型-epub-与-pdf-云端按需阅读)。

ZIP/CBZ、图片型 EPUB 和 PDF 按需阅读均要求实际文件服务支持 HTTP Range。服务器忽略 Range、返回整个文件或无效分段时会明确失败，不会自动下载整个文件；通过网盘直链、代理或重定向访问时同样适用。ZIP/ZIP64 支持 Store/Deflate，不支持加密、分卷或其他压缩方式；ZIP 内的 PDF 不作为漫画页面读取。PDF 不支持加密或需要密码的文件。7z/CB7 不能直接云端按需阅读，可先下载后本地导入，或将漫画图片解压到远端目录。

旧 WebDAV 同步和归档配置会自动接入统一账号，保留原同步目录和归档目录。本地漫画位置、缓存与下载线程归入“本地存储与下载”，手动数据导入和导出归入“应用数据导入与导出”。

所有已保存的网盘账号及授权信息都会随应用数据快照同步，包括尚未用于漫画库的账号。恢复快照时，本机仍有效的授权优先保留；数据同步目标始终保留在本机。漫画备份配置是否同步由“同步备份配置”选项决定。

网盘账号名称必须唯一，比较时忽略首尾空格和英文大小写。同一账号在不同设备上请使用相同名称，不同账号请使用不同名称；同步时，同名且网盘类型相同的账号会自动合并，并更新漫画库、同步和备份目录的账号引用，保留漫画库标识与收藏关联。同名但类型不同的账号会保留，并自动添加名称后缀以区分。修改账号名称仍保留内部账号标识。

本次改动的原生 OpenList 编译、各平台加载和六种网盘实机验证尚未在本地运行；它们安排在 CI 和专用测试目录完成。ZIP/CBZ、图片型 EPUB 和 PDF 云端按需阅读，以及云端主页的实体墨水屏表现，尚未完成各平台及真实网盘的端到端实测；具体存储服务的 Range 兼容性须以实际响应为准。

macOS 应用仍支持 macOS 12；受 Go 1.27 运行时限制，OpenList 六种网盘仅在 macOS 13 及以上可用。在 macOS 12 上，WebDAV 和本地功能仍可使用。
